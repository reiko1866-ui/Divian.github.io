# Mesehang

Interaktív mesekészítő a Divian.github.io oldalon.

1. Mondd be vagy írd be, milyen mesét szeretnél.
2. Válassz hangulatot, és (ha akarod) add meg a hős nevét.
3. A mese közben döntésekkel irányítod a történetet.
4. Felolvastathatod, és a végén elmentheted szövegként.

Nyisd meg az `index.html` fájlt, vagy GitHub Pages-en a repository oldalát.
